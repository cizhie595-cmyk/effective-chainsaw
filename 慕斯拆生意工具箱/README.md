## 安装方式

Claude Code 用户：

1. 复制 `skills/` 下需要的 skill 目录。
2. 粘贴到 `~/.claude/skills/`。
3. 在 Claude Code 中直接点名对应 skill 使用，例如“用慕斯拆生意机器看看这个生意”。

非 Claude 用户：

直接打开任意 `SKILL.md`，把正文当作 prompt 贴给任何 AI，也能运行。这个仓库的目标是扩大可用人群，不把工具锁死在单一客户端里。
